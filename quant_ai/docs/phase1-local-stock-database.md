# 第一阶段：本地股票数据库

第一阶段只做一件事：把本地股票数据库打牢。

## 目标

- 保存 A 股股票基础信息
- 保存日线行情数据
- 保存财务报告数据
- 预留新闻数据表
- 支持后续每日增量更新

## 已建立的核心表

- `stocks`：股票基础信息
- `daily_prices`：日 K 行情
- `financial_reports`：财务数据
- `news`：新闻数据

## 当前第一个采集器

`data_collector/stock_list_collector.py` 会通过 AkShare 获取 A 股股票列表，并写入 `stocks` 表。

后续建议按这个顺序继续：

1. 增加日 K 数据采集器
2. 增加每日增量更新脚本
3. 增加财务数据采集器
4. 加入日志和任务调度
5. 再接入 C++ 量化核心
